# Crusher (Trituradora) - NeoForge 1.21.1

Compilar:   ./gradlew build        (Windows: gradlew.bat build)
Probar:     ./gradlew runClient    (abre Minecraft con el mod, sin instalar nada)
El .jar sale en: build/libs/crusher-1.0.0.jar

Requisitos: JDK 21 y, para jugar, NeoForge 1.21.1 instalado.
Instalar: copia el .jar a la carpeta mods de tu instancia (y al server, si juegas en uno).

Sin instalar nada: sube la carpeta a un repo de GitHub; la pestaña Actions compila y deja el .jar para descargar.
